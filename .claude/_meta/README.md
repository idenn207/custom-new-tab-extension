# 메타 조사 (`_meta`)

증상이 여럿이고 서로 얽혀 있어 PRD를 바로 쓸 수 없을 때, **무엇부터 고쳐야 하는가**를 조사해
판정으로 남기는 곳입니다. 각 문서는 `/mccp:meta-research`가 만들고, 아래 색인에 등재됩니다.

- 산출물 이름 규칙: `<YYYY-MM-DD>-<ascii-slug>.md`
- 조사는 게이트가 아닙니다 — 다음 단계를 막지도, 열지도 않습니다.
- 인용한 코드가 이후 바뀌면 그 문서의 `**Status**`를 갱신하고 `register`를 다시 돌립니다.
