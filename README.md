# Custom New Tab Extension

랜덤/고정 배경 이미지, 즐겨찾기 고정 기능이 적용되는 Chrome New Tab 확장 프로그램

## 기능

- ⏰ **실시간 시계**: HH:mm 형식으로 표시 (고정폭 숫자라 분이 바뀌어도 폭이 흔들리지 않습니다)
- 🗓️ **업무 달력**: 메인 위젯을 시계 대신 달력으로 전환. 상단 전체 너비 밴드에 월간 그리드 + 기간 일정 + 중요도 + 작업 메모
- 🔍 **통합 검색**: Google 검색 및 URL 직접 입력
- ⭐ **즐겨찾기**: 좌측 collapse 메뉴, 고정 기능 지원
- 📌 **고정 즐겨찾기**: 자주 사용하는 즐겨찾기를 화면에 바로 표시
- 🖼️ **이미지 업로드**: 최대 50개 이미지 업로드 가능
- 🌅 **랜덤/고정 배경**: 랜덤 또는 고정 이미지 모드 선택
- 📅 **날짜 표시**: 우측 하단에 날짜 및 요일 표시
- ⚙️ **설정**: 메인 위젯 종류·위치, 검색창 위치, 배경 이미지 모드, 오버레이
- 🎨 **다크모드**: 배경 색상에 적응하는 다크 테마

## UI 구성

### 좌측 상단

- **빠른이동 아이콘**: 클릭하면 전체 즐겨찾기 목록 표시 (사이드바)
- **고정된 즐겨찾기**: 고정한 즐겨찾기가 바로 표시됨

### 중앙

- **메인 위젯**: 시계 또는 달력 중 하나 (설정 > 위젯에서 전환)
  - **시계**: HH:mm 형식, 대형 폰트. 9분할 위치 선택 가능
  - **달력**: 화면 **상단 전체 너비 밴드**. 월간 6주 그리드 + 오른쪽 할 일 패널.
    위치를 고르지 않으므로 달력 모드에서는 위젯 위치 그리드가 숨겨집니다
    (시계로 되돌리면 이전에 고른 위치가 그대로 복원됩니다)
- **검색바**: Google 검색 또는 URL 입력. 달력 밴드가 켜져 있고 검색창이 위쪽이면 밴드 아래로 자동으로 내려갑니다

### 우측 상단

- **이미지 관리 아이콘**: 클릭하면 업로드 이미지 목록 표시 (사이드바)
- **설정 아이콘**: 배경 이미지 모드 설정

### 우측 하단

- **날짜**: yyyy년 mm월 dd일 요일

## 배경 이미지

### 이미지 우선순위

1. 업로드한 이미지가 있으면 → 업로드 이미지만 사용
2. 업로드한 이미지가 없으면 → 로컬 이미지 사용

### 배경 모드

- **랜덤 모드** (기본): 새 탭을 열 때마다 다른 이미지 표시
- **고정 모드**: 한 번 선택된 이미지가 계속 표시됨

## 설치 방법

### 1. 배경 이미지 준비 (선택사항)

로컬 이미지를 사용하려면 `my-newtab-extension/images/` 폴더에 이미지를 추가하세요:

```plaintext
images/
├── 1.jpg
├── 2.jpg
├── 3.jpg
└── ...
```

**참고**: 로컬 이미지 없이도 확장 프로그램을 설치한 후 UI에서 직접 이미지를 업로드할 수 있습니다.

### 2. Chrome에 확장 프로그램 로드

1. Chrome 브라우저를 열고 주소창에 입력:

   ```plaintext
   chrome://extensions/
   ```

2. 오른쪽 상단의 **개발자 모드** 활성화

3. **압축해제된 확장 프로그램을 로드합니다** 클릭

4. `my-newtab-extension` 폴더 선택

5. 새 탭을 열어서 확인!

## 사용 방법

### 검색하기

- 검색창에 텍스트 입력 → Google 검색
- URL 입력 (예: github.com) → 해당 사이트로 이동

### 즐겨찾기 관리

1. **좌측 상단 아이콘** 클릭 → 즐겨찾기 사이드바 열기
2. **+ 아이콘** 클릭 → 새 즐겨찾기 추가
3. **📌 아이콘** 클릭 → 즐겨찾기 고정/해제
4. **× 버튼** 클릭 → 즐겨찾기 삭제

**고정된 즐겨찾기**: 좌측 상단에 바로 표시되어 빠르게 접근 가능

### 배경 이미지 관리

1. **우측 상단 이미지 아이콘** 클릭 → 이미지 사이드바 열기
2. **이미지 업로드** 영역 클릭 또는 드래그 앤 드롭
3. 이미지 클릭 → 미리보기 (고정 모드에서는 해당 이미지로 고정)
4. **× 버튼** 클릭 → 이미지 삭제

**제한사항**:

- 최대 50개 이미지
- 파일당 최대 15MB
- 지원 포맷: JPG, PNG, WEBP

### 달력 사용하기

1. **우측 상단 설정 아이콘** > **위젯** > **위젯 종류**에서 `달력` 선택. 화면 상단에 전체 너비 밴드가 나타납니다
2. 날짜를 클릭하면 **오른쪽에** 할 일 패널이 열립니다

**간편 입력 (하루짜리)**

패널 아래 입력창에 마감할 일을 적고 Enter. 체크로 완료, ×로 삭제.

**상세 입력 (기간 · 중요도 · 메모)**

헤더 오른쪽의 **`일정 추가`** 버튼, 또는 목록 항목의 **`편집`** 버튼을 누르면 상세 창이 열립니다.

| 항목 | 설명 |
|---|---|
| 시작일 / 종료일 | 하루를 넘는 기간 일정. 최대 366일 |
| 중요도 | `보통 이하` / `보통` / `중요` 3단계 |
| 작업 메모 | 진행 상황 기록. 최대 2000자 |

종료일이 시작일보다 빠르거나 366일을 넘으면 **저장하지 않고 그 자리에서 알려 줍니다.** 조용히 고쳐서 저장하지 않습니다.

### 관문 — 마감이 하나가 아닐 때

작업 하나에 마감이 하나뿐이라는 전제를 걷어냈습니다. 작업은 서로 다른 날짜의 **관문(gate)** 집합을
가지며, 상세 창 안의 관문 편집기에서 더하고 고칩니다.

| 항목 | 설명 |
|---|---|
| 종류 | `dev` · `review` · `stg` · `prod` · `monitor` 또는 **이름 없음**. 코드 상수라 목록을 늘리려면 `GATE_KINDS` 한 줄을 고칩니다 |
| 계획일 | 그 관문을 지나기로 한 날 |
| 완료 | 누르면 그날이 **실제일**로 남습니다. 계획보다 이르면 `조기`, 늦으면 `지연`으로 그 자리에 한 줄 표시됩니다 |
| 범위축소 | "안 하기로" 한 관문. **지우지 않고 남깁니다** — 지우면 범위를 줄였다는 사실 자체가 사라집니다 |

몇 가지가 조용히 지켜집니다.

- **시작일·종료일은 이제 저장되지 않고 관문에서 파생됩니다** (`min`..`max`). 그래서 관문을 고치면 기간이
  따라 움직이고, 상세 창의 날짜 칸은 관문을 손댄 작업에서 읽기 전용이 됩니다 — 편집할 수 있는 것처럼
  보이는 칸이 조용히 무시되지 않게 하기 위해서입니다
- **마감 판정은 살아 있는 관문 중 가장 늦은 것 하나만 봅니다.** 관문 전부가 마감을 만들면 지나간 시작일이
  전부 지연으로 잡혀, 다음 날 아침 요약이 **없던 지연 건수**를 보고합니다
- **범위축소한 관문은 마감 판정에서 빠집니다.** 범위를 줄인 행위가 늦은 것으로 뒤집히면 안 되기 때문입니다.
  다만 기간과 셀 점유에는 그대로 남습니다 — 계획은 남습니다
- **마지막 관문은 지워지지 않습니다.** 관문이 하나도 없는 작업은 존재할 수 없습니다
- 관문 하나를 옮겨도 **다른 관문은 움직이지 않습니다.** 자동 재배치를 하지 않습니다

### 프로젝트

> 이번 단계에 들어간 것은 **데이터 계층 · 상세 창의 프로젝트 선택기 · 첫 실행 안내**까지입니다.
> 프로젝트의 **이름을 바꾸고 지우는** 화면은 다음 단계에 옵니다 — 그때까지 선택기에는 첫 실행
> 안내로 만든 프로젝트와 `무소속`만 보입니다. 아래 규칙은 그 화면이 붙었을 때의 동작이고,
> 저장 규칙 자체는 이미 서 있습니다.

프로젝트가 하나도 없는 첫 로드에서 **프로젝트를 하나 만들지 묻는 안내가 한 번** 뜹니다. 만들거나
건너뛰면 다시 뜨지 않습니다 — 무소속이 정상 상태이므로 반복해서 묻는 것은 사실상 강제입니다.
설정이나 프로젝트 목록을 **읽지 못한 상태에서는 뜨지 않습니다.** 그 상태는 첫 실행이 아니라 읽기
실패이고, 그때 필요한 말은 "프로젝트를 만드시겠어요?" 가 아니라 목록을 못 읽었다는 고지입니다.

작업을 프로젝트로 묶습니다. **강제하지 않습니다** — 새 일정의 기본값은 마지막에 쓴 프로젝트이고,
언제나 `무소속` 자리가 남아 있습니다.

프로젝트를 지워도 **그 프로젝트를 가리키던 작업은 지워지지 않습니다.** 무소속으로 내려갈 뿐입니다.
이름을 바꿔도 작업을 훑지 않습니다 — 참조가 이름이 아니라 id 로 걸려 있기 때문입니다.

프로젝트 목록을 읽지 못하면 **프로젝트 변경만 잠깁니다.** 읽지 못한 목록을 근거로 "이 프로젝트는 없다"고
판단하면 저장소에 멀쩡히 있는 프로젝트를 가리키던 작업이 전부 무소속으로 내려앉기 때문입니다.

### 내보내기 파일의 형식

내보내기는 이제 **버전 봉투**를 씌웁니다.

```json
{ "version": 4, "events": [ ... ] }
```

가져오기는 이 봉투와 **옛 형식(맨 배열)** 둘만 읽고 나머지는 전부 거절합니다. 모르는 형식을 추측해서
읽지 않습니다. 그리고 **항목 하나라도 읽을 수 없으면 파일 전체를 거절합니다** — 일부만 들어오면
무엇이 빠졌는지 모른 채 "가져왔다"고 믿게 되기 때문입니다.

**화면 읽는 법**

- **칸을 채우는 것은 기간이 아니라 관문입니다.** 관문의 계획일(`planned`)이 있는 날짜 칸만 차고
  **사이 날짜는 빕니다** — 월·수 관문이면 화요일 칸은 비어 보입니다. 상세 패널도 같은 규칙으로
  답하므로 그리드에서 빈 칸을 눌러도 그 작업은 나오지 않고, 패널의 날짜 줄도 `시작일 – 종료일`
  범위가 아니라 **관문 날짜를 열거**합니다
- **범위축소(`dropped`)한 관문의 날짜도 그대로 찹니다.** 안 하기로 한 것과 애초에 없던 것은
  다르고, 계획은 남습니다. 다만 그 칸에는 마감 상태를 붙이지 않습니다 — 범위를 줄인 날이
  지연으로 읽히면 안 되기 때문입니다
- 날짜 칸의 **막대(칩)** 하나가 일정 하나입니다. 칸당 최대 2개 + `+N`
- 막대의 **모서리 모양**이 그 작업 안에서 이 관문의 자리를 말합니다 — 양끝이 둥글면 관문이 하나뿐,
  한쪽만 둥글면 첫 관문/마지막 관문, 양끝이 각지면 중간 관문입니다. 칸이 불연속이므로 각진 끝이
  **이웃 칸으로 이어진다는 뜻은 아닙니다** (관문의 시각 언어 자체는 다음 단계에서 다시 봅니다)
- 막대의 **두께**가 중요도입니다 (얇음 → 두꺼움). 색이 아니라 두께라서 화면을 흑백으로 봐도 구분됩니다
- 기한이 지난 일정은 빨강, 내일 마감은 주황
- 밴드 헤더 오른쪽에 **`오늘 마감 2건 · 지연 1건`** 한 줄이 뜹니다. 셀 것이 없으면 아무것도 표시하지 않습니다

**키보드만으로 조작하기**

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` | 날짜 이동 |
| `Home` / `End` | 주의 처음 / 끝 |
| `PageUp` / `PageDown` | 이전 달 / 다음 달 |
| `Enter` / `Space` | 날짜 선택 (할 일 패널 열기) |
| `Shift` + `←` `→` `↑` `↓` | 기간 선택 (여러 날 잡기) |
| 기간을 잡은 뒤 `Enter` | 그 기간으로 상세 창 열기 |
| `Esc` | 할 일 패널 닫기 / 상세 창 닫기 |

상세 창 안에서는 `Tab`이 창 밖으로 나가지 않고, `Esc` 한 번으로 창만 닫힙니다 (뒤의 패널은 그대로 남습니다).

**할 일 백업**

할 일은 이 브라우저에만 저장됩니다. 확장 프로그램을 지우거나 프로필을 초기화하면 복구할 수 없으므로,
**설정 > 위젯 > 달력 데이터**에서 주기적으로 JSON으로 내보내 두세요. 가져오기는 기존 할 일을 전부 교체합니다.

### 설정

1. **우측 상단 설정 아이콘** 클릭
2. **위젯** 탭
   - **위젯 표시** 토글: 메인 위젯 표시/숨김
   - **위젯 종류**: 시계 / 달력
   - **위젯 위치**: 9분할 그리드에서 선택. **달력 모드에서는 숨겨집니다** (밴드는 항상 상단 전체 너비).
     고른 위치는 지워지지 않으므로 시계로 되돌리면 그대로 복원됩니다
   - **검색창 위치**: 9분할 그리드에서 선택. 달력 모드에서도 그대로 쓸 수 있습니다
   - **달력 데이터**: 할 일 내보내기 / 가져오기 (달력 모드에서만 표시)
3. **배경** 탭
   - **배경 이미지 모드** 토글
     - **랜덤**: 새 탭마다 다른 이미지
     - **고정**: 현재 이미지 유지
   - **블러 효과**, **오버레이 밝기**

## 커스터마이징

### 색상 테마 변경

`newtab.css` 파일의 `:root` 변수를 수정:

```css
:root {
  --bg-primary: rgba(20, 20, 25, 0.85);
  --bg-secondary: rgba(30, 30, 35, 0.9);
  --text-primary: rgba(255, 255, 255, 0.95);
  --accent-color: rgba(100, 150, 255, 0.8);
}
```

### 최대 업로드 이미지 개수 변경

`newtab.js` 파일의 `ImageManager` 클래스:

```javascript
constructor(sidebar, toggleBtn, backgroundManager) {
  // ...
  this.maxImages = 50; // 원하는 개수로 변경
}
```

### 시계 폰트 크기 변경

`newtab.css`의 `:root` 토큰을 바꿉니다. `.time` 규칙은 이 토큰만 읽으므로 한 곳만 고치면 됩니다.

```css
:root {
  --text-display: 9rem; /* 144px. 원하는 크기로 변경 */
}
```

좁은 화면용 값은 파일 아래쪽 반응형 블록에서 같은 토큰을 덮습니다 (≤1024px에서 `6.75rem`, ≤768px에서 `5rem`).

### 위치 회귀 스모크 하네스

빌드 도구나 테스트 프레임워크 없이, 실제 `newtab.html`을 iframe으로 띄워 프로덕션 위치 로직을 그대로 구동하는 검증 페이지입니다.

1. `chrome://extensions`에서 확장 프로그램 ID 확인
2. 주소창에 `chrome-extension://<확장 ID>/test/positioning.smoke.html` 입력
3. 코드 변경 **전**에 `베이스라인 캡처`
4. 코드 변경 **후**에 `비교 실행` → 차이 0 확인

위젯 9위치 × 검색창 9위치 × 위젯 종류 2종, 토글 조합, 위젯 전환·월 이동·패널 펼침·리사이즈 같은 동적 전이,
설정 마이그레이션 멱등성, 날짜 키 헬퍼 테이블, 가져오기 정제 규칙, 스토리지 백엔드 선택, 읽기 실패 시 데이터 보존,
오류 배너 기하를 검사합니다. 실행 중 스토리지를 임시로 덮어쓰지만 종료 시 원래 값으로 복원합니다.

판정은 두 축입니다. **차이**는 베이스라인 대비 스냅샷 변화이고, **단언 실패**는 베이스라인과 무관합니다 —
베이스라인을 다시 떠도 단언 실패는 사라지지 않으므로, 잘못된 값이 새 기준으로 굳는 것을 막습니다.

## 저장소 동작

### 어디에 저장되는가

확장 프로그램으로 로드했을 때는 `chrome.storage.local`에 저장됩니다. 백엔드는 **시작할 때 한 번** 정해지고
실행 중에 바뀌지 않습니다. 저장이 실패했다고 다른 곳으로 옮겨 담으면, 적어둔 것이 기대와 다른 자리에 쌓이는데
화면은 성공한 것처럼 보이기 때문입니다.

### 로컬 서버 미리보기 (`http://localhost:...`)

확장 오리진이 아닌 곳에서는 `chrome.storage`가 존재하지 않습니다. 이때는 그 브라우저의 `localStorage`에
저장하며, 화면 아래에 **"미리보기 모드"** 고지가 뜹니다. 두 가지를 알아두세요.

- **확장의 데이터와 별개입니다.** 미리보기에서 적은 일정은 확장에 나타나지 않고, 그 반대도 마찬가지입니다.
- **그 오리진에 평문으로 남습니다.** `localStorage`는 오리진과 포트 단위로 격리되므로, 같은 주소·포트에서
  띄우는 다른 페이지가 읽을 수 있습니다. 실제 마감이나 작업 메모를 미리보기에 적지 마세요.
  지우려면 개발자 도구에서 해당 오리진의 `__newTabPreviewStorage__` 키를 삭제하면 됩니다.

### 읽기에 실패하면

저장된 값이 손상됐거나 저장소를 읽지 못하면, 앱은 **빈 목록인 척하지 않습니다.** 오류 배너를 띄우고
저장을 잠급니다. 잠긴 동안에는 할 일 추가·완료·삭제와 내보내기가 모두 거절됩니다.

빈 목록을 정상으로 취급하면 할 일을 하나만 추가해도 그 한 건이 통째로 커밋되어 저장돼 있던 일정이
전부 사라지기 때문입니다. 잠금을 푸는 길은 둘입니다.

- 배너의 **다시 시도** — 일시적인 오류였다면 이걸로 풀립니다
- **파일에서 가져오기** — 저장값이 영구히 손상된 경우의 복구 경로입니다. 전체를 교체하므로 잠금을 통과합니다

## SOLID 원칙 적용

- **단일 책임 원칙**: 각 클래스는 하나의 책임만 가짐

  - `ClockManager`: 시계 관리
  - `BackgroundManager`: 배경 이미지 관리 (랜덤/고정 모드)
  - `SearchManager`: 검색 관리
  - `BookmarkManager`: 즐겨찾기 관리 (고정 기능 포함)
  - `ImageManager`: 이미지 업로드 및 UI 관리
  - `SettingsManager`: 설정 관리
  - `Application`: 초기화 조율

- **개방-폐쇄 원칙**: 확장에는 열려있고 수정에는 닫혀있음
- **인터페이스 분리 원칙**: 필요한 메서드만 공개
- **의존성 역전 원칙**: 추상화에 의존

## 문제 해결

### 배경 이미지가 표시되지 않음

- 이미지를 업로드했는지 확인
- `images/` 폴더에 로컬 이미지가 있는지 확인 (선택사항)
- Chrome 확장 프로그램 페이지에서 새로고침

### 이미지 업로드가 안됨

- 파일 크기가 15MB 이하인지 확인
- 이미지 개수가 50개 미만인지 확인
- 이미지 포맷이 JPG, PNG, WEBP인지 확인

### 고정 모드가 작동하지 않음

- 설정에서 고정 모드로 변경했는지 확인
- 고정하려는 이미지를 한 번 클릭하세요

### 즐겨찾기가 표시되지 않음

- 좌측 상단 아이콘을 클릭하여 사이드바 열기
- 📌 아이콘을 눌러 즐겨찾기 고정

### 폰트가 표시되지 않음

- 인터넷 연결 확인 (Google Fonts 사용)
- 오프라인 사용시 시스템 폰트로 자동 대체됨
