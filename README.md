# Custom New Tab Extension

랜덤/고정 배경 이미지, 즐겨찾기 고정 기능이 적용되는 Chrome New Tab 확장 프로그램

## 기능

- ⏰ **실시간 시계**: HH:mm 형식으로 표시 (Nanum Gothic 폰트)
- 🗓️ **달력 위젯**: 메인 위젯을 시계 대신 달력으로 전환 가능. 월간 그리드 + 날짜별 할 일(마감일) 관리
- 🔍 **통합 검색**: Google 검색 및 URL 직접 입력
- ⭐ **즐겨찾기**: 좌측 collapse 메뉴, 고정 기능 지원
- 📌 **고정 즐겨찾기**: 자주 사용하는 즐겨찾기를 화면에 바로 표시
- 🖼️ **이미지 업로드**: 최대 50개 이미지 업로드 가능
- 🌅 **랜덤/고정 배경**: 랜덤 또는 고정 이미지 모드 선택
- 📅 **날짜 표시**: 우측 하단에 날짜 및 요일 표시
- ⚙️ **설정**: 메인 위젯 종류·위치, 검색창 위치, 배경 이미지 모드, 오버레이
- 🎨 **다크모드**: 배경 색상에 적응하는 다크 테마

## UI 구성

### 좌측 상단

- **빠른이동 아이콘**: 클릭하면 전체 즐겨찾기 목록 표시 (사이드바)
- **고정된 즐겨찾기**: 고정한 즐겨찾기가 바로 표시됨

### 중앙

- **메인 위젯**: 시계 또는 달력 중 하나 (설정 > 위젯에서 전환)
  - **시계**: HH:mm 형식, 대형 폰트
  - **달력**: 월간 6주 그리드. 날짜를 누르면 아래로 할 일 패널이 펼쳐짐
- **검색바**: Google 검색 또는 URL 입력

### 우측 상단

- **이미지 관리 아이콘**: 클릭하면 업로드 이미지 목록 표시 (사이드바)
- **설정 아이콘**: 배경 이미지 모드 설정

### 우측 하단

- **날짜**: yyyy년 mm월 dd일 요일

## 배경 이미지

### 이미지 우선순위

1. 업로드한 이미지가 있으면 → 업로드 이미지만 사용
2. 업로드한 이미지가 없으면 → 로컬 이미지 사용

### 배경 모드

- **랜덤 모드** (기본): 새 탭을 열 때마다 다른 이미지 표시
- **고정 모드**: 한 번 선택된 이미지가 계속 표시됨

## 설치 방법

### 1. 배경 이미지 준비 (선택사항)

로컬 이미지를 사용하려면 `my-newtab-extension/images/` 폴더에 이미지를 추가하세요:

```plaintext
images/
├── 1.jpg
├── 2.jpg
├── 3.jpg
└── ...
```

**참고**: 로컬 이미지 없이도 확장 프로그램을 설치한 후 UI에서 직접 이미지를 업로드할 수 있습니다.

### 2. Chrome에 확장 프로그램 로드

1. Chrome 브라우저를 열고 주소창에 입력:

   ```plaintext
   chrome://extensions/
   ```

2. 오른쪽 상단의 **개발자 모드** 활성화

3. **압축해제된 확장 프로그램을 로드합니다** 클릭

4. `my-newtab-extension` 폴더 선택

5. 새 탭을 열어서 확인!

## 사용 방법

### 검색하기

- 검색창에 텍스트 입력 → Google 검색
- URL 입력 (예: github.com) → 해당 사이트로 이동

### 즐겨찾기 관리

1. **좌측 상단 아이콘** 클릭 → 즐겨찾기 사이드바 열기
2. **+ 아이콘** 클릭 → 새 즐겨찾기 추가
3. **📌 아이콘** 클릭 → 즐겨찾기 고정/해제
4. **× 버튼** 클릭 → 즐겨찾기 삭제

**고정된 즐겨찾기**: 좌측 상단에 바로 표시되어 빠르게 접근 가능

### 배경 이미지 관리

1. **우측 상단 이미지 아이콘** 클릭 → 이미지 사이드바 열기
2. **이미지 업로드** 영역 클릭 또는 드래그 앤 드롭
3. 이미지 클릭 → 미리보기 (고정 모드에서는 해당 이미지로 고정)
4. **× 버튼** 클릭 → 이미지 삭제

**제한사항**:

- 최대 50개 이미지
- 파일당 최대 15MB
- 지원 포맷: JPG, PNG, WEBP

### 달력 사용하기

1. **우측 상단 설정 아이콘** > **위젯** > **위젯 종류**에서 `달력` 선택
2. 날짜를 클릭하면 아래로 할 일 패널이 펼쳐짐
3. 입력창에 마감할 일을 적고 Enter로 추가. 체크로 완료, ×로 삭제
4. 날짜 셀의 점은 그 날 등록된 할 일 개수 (최대 3개 + `+N`)
5. 기한이 지난 날은 빨강, 내일 마감은 주황으로 표시됨

**키보드만으로 조작하기**

| 키 | 동작 |
| --- | --- |
| `←` `→` `↑` `↓` | 날짜 이동 |
| `Home` / `End` | 주의 처음 / 끝 |
| `PageUp` / `PageDown` | 이전 달 / 다음 달 |
| `Enter` / `Space` | 날짜 선택 (할 일 패널 열기) |
| `Esc` | 할 일 패널 닫기 |

**할 일 백업**

할 일은 이 브라우저에만 저장됩니다. 확장 프로그램을 지우거나 프로필을 초기화하면 복구할 수 없으므로,
**설정 > 위젯 > 달력 데이터**에서 주기적으로 JSON으로 내보내 두세요. 가져오기는 기존 할 일을 전부 교체합니다.

### 설정

1. **우측 상단 설정 아이콘** 클릭
2. **위젯** 탭
   - **위젯 표시** 토글: 메인 위젯 표시/숨김
   - **위젯 종류**: 시계 / 달력
   - **위젯 위치**, **검색창 위치**: 9분할 그리드에서 선택
   - **달력 데이터**: 할 일 내보내기 / 가져오기 (달력 모드에서만 표시)
3. **배경** 탭
   - **배경 이미지 모드** 토글
     - **랜덤**: 새 탭마다 다른 이미지
     - **고정**: 현재 이미지 유지
   - **블러 효과**, **오버레이 밝기**

## 커스터마이징

### 색상 테마 변경

`newtab.css` 파일의 `:root` 변수를 수정:

```css
:root {
  --bg-primary: rgba(20, 20, 25, 0.85);
  --bg-secondary: rgba(30, 30, 35, 0.9);
  --text-primary: rgba(255, 255, 255, 0.95);
  --accent-color: rgba(100, 150, 255, 0.8);
}
```

### 최대 업로드 이미지 개수 변경

`newtab.js` 파일의 `ImageManager` 클래스:

```javascript
constructor(sidebar, toggleBtn, backgroundManager) {
  // ...
  this.maxImages = 50; // 원하는 개수로 변경
}
```

### 시계 폰트 크기 변경

`newtab.css` 파일의 `.time` 클래스:

```css
.time {
  font-size: 144px; /* 원하는 크기로 변경 */
}
```

## 파일 구조

```plaintext
my-newtab-extension/
├── manifest.json       # 확장 프로그램 설정
├── newtab.html         # HTML 구조
├── newtab.css          # 스타일링
├── newtab.js           # 기능 구현
├── test/               # 위치 회귀 스모크 하네스 (의존성 0)
│   ├── positioning.smoke.html
│   └── positioning.smoke.js
└── images/             # 로컬 배경 이미지 (선택사항)
    ├── 1.jpg
    ├── 2.jpg
    └── ...
```

### 위치 회귀 스모크 하네스

빌드 도구나 테스트 프레임워크 없이, 실제 `newtab.html`을 iframe으로 띄워 프로덕션 위치 로직을 그대로 구동하는 검증 페이지입니다.

1. `chrome://extensions`에서 확장 프로그램 ID 확인
2. 주소창에 `chrome-extension://<확장 ID>/test/positioning.smoke.html` 입력
3. 코드 변경 **전**에 `베이스라인 캡처`
4. 코드 변경 **후**에 `비교 실행` → 차이 0 확인

위젯 9위치 × 검색창 9위치 × 위젯 종류 2종, 토글 조합, 위젯 전환·월 이동·패널 펼침·리사이즈 같은 동적 전이,
설정 마이그레이션 멱등성, 날짜 키 헬퍼 테이블, 가져오기 정제 규칙을 검사합니다.
실행 중 스토리지를 임시로 덮어쓰지만 종료 시 원래 값으로 복원합니다.

## 기술 스택

- Vanilla JavaScript (ES6+)
- Chrome Extensions Manifest V3
- Chrome Storage API
- CSS3 (Grid, Flexbox, Backdrop Filter)
- Google Fonts (Nanum Gothic)

## SOLID 원칙 적용

- **단일 책임 원칙**: 각 클래스는 하나의 책임만 가짐

  - `ClockManager`: 시계 관리
  - `BackgroundManager`: 배경 이미지 관리 (랜덤/고정 모드)
  - `SearchManager`: 검색 관리
  - `BookmarkManager`: 즐겨찾기 관리 (고정 기능 포함)
  - `ImageManager`: 이미지 업로드 및 UI 관리
  - `SettingsManager`: 설정 관리
  - `Application`: 초기화 조율

- **개방-폐쇄 원칙**: 확장에는 열려있고 수정에는 닫혀있음
- **인터페이스 분리 원칙**: 필요한 메서드만 공개
- **의존성 역전 원칙**: 추상화에 의존

## 문제 해결

### 배경 이미지가 표시되지 않음

- 이미지를 업로드했는지 확인
- `images/` 폴더에 로컬 이미지가 있는지 확인 (선택사항)
- Chrome 확장 프로그램 페이지에서 새로고침

### 이미지 업로드가 안됨

- 파일 크기가 15MB 이하인지 확인
- 이미지 개수가 50개 미만인지 확인
- 이미지 포맷이 JPG, PNG, WEBP인지 확인

### 고정 모드가 작동하지 않음

- 설정에서 고정 모드로 변경했는지 확인
- 고정하려는 이미지를 한 번 클릭하세요

### 즐겨찾기가 표시되지 않음

- 좌측 상단 아이콘을 클릭하여 사이드바 열기
- 📌 아이콘을 눌러 즐겨찾기 고정

### 폰트가 표시되지 않음

- 인터넷 연결 확인 (Google Fonts 사용)
- 오프라인 사용시 시스템 폰트로 자동 대체됨
